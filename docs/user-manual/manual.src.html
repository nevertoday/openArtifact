USER MANUAL

Open Artifact 使用手册

让任何 AI agent 把文档、报告、看板发布成网页，整个团队打开就能看、能评论、能用；再让 agent 按评论去改。

01Open Artifact 是什么

你平时让 Claude Code、Codex、Cursor 这类 agent 写设计文档、分析报告或数据看板。Open Artifact 把这些结果发布成一个个网页，叫作 artifact。同事不需要任何 AI 账号，用团队账号登录就能打开。

1

agent 发布

你对 agent 说“发布到 Open Artifact”，它把页面发上来并给你一个链接。

2

团队查看和评论

同事打开链接，在旁边写评论；需要 agent 改的，勾选「给 agent 处理」。

3

agent 修改

你让 agent 处理评论，它改完发布新版本，再回复评论并标记已解决。

02登录

  1. 打开 Open Artifact 的地址，输入工作邮箱，点「发送登录链接」。
  2. 打开邮件里的链接，就登录了。链接 5 分钟内有效，只能用一次。
  • 只有管理员允许的邮箱域名可以注册。用了别的邮箱，页面会提示允许哪些域名。
  • 第一个登录的人成为团队 workspace 的管理员，之后登录的人自动成为成员。
  • 如果团队配置了公司 SSO、GitHub 或 Google，登录页会多出对应的按钮。

本地试用时没有邮件服务，登录链接打印在运行 pnpm dev 的终端里，搜索 [mail]。

03首页

首页列出你能看到的 artifact，最近更新的在前面。每张卡片上有：

  • 页面的实时缩略预览（最前面的 12 张卡片）。
  • 标题和可见范围（例如「Workspace 内可见」「公开链接」）。
  • 作者、发布来源（哪个 agent 发布的，圆点颜色区分 agent）、版本号、更新时间。
  • N 条评论待 agent 处理：有人留了给 agent 的评论，还没解决。

左侧可以筛选：全部、我发布的、共享给我（别人单独授权给你的）、待 agent 处理，以及按发布来源筛选。顶部可以按标题搜索。你属于多个 workspace 时，顶部可以切换。

04查看 artifact

点开一张卡片进入查看页：左边是页面本身，右边是「评论」「版本」「数据」三个标签。

  • 页面在沙箱里运行，和 Open Artifact 不在同一个网站。页面里的代码拿不到你的登录信息，所以 agent 写的任何页面都可以放心打开。
  • 「新标签页打开」会单独打开页面本身。这个地址 6 小时内有效，过期后回到 Open Artifact 重新打开即可。
  • 作者能看到「分享」按钮，用来改谁能看到（见 分享）。

05评论和「给 agent」

能评论的人在右侧「评论」标签底部写评论。

  • 在页面上标注位置：写评论前点「在页面上标注位置」，再点左边页面上要说的地方。页面上会出现带编号的标记，评论旁边显示同样的编号；点页面上的标记，右边会跳到对应的评论。已解决的评论不再显示标记。
  • 勾选「给 agent 处理」：这条评论是给 agent 的修改意见。agent 读取评论时只会拿到这类未解决的评论，不会被普通讨论干扰。这类评论用黄色底标出。
  • 回复：每条评论下面可以回复。agent 的回复会标出是哪个 agent，例如「Claude Code（代 林舟）」。
  • 标记已解决 / 重新打开：处理完的评论标记为已解决，需要时可以重新打开。
  • 上方的筛选：未解决、给 agent、全部。

邮件通知：有人评论你发布的 artifact，或者回复你的评论时，你会收到邮件。自己的操作不会通知自己。

06版本

  • agent 每次修改都会发布一个新版本，旧版本全部保留。「版本」标签列出每个版本、发布人、发布来源和时间。
  • 点「查看」打开旧版本，页面顶部会提示你在看旧版本。
  • 能编辑的人可以点「恢复为当前版本」：旧版本的内容会作为一个新版本发布，历史不会被改写。
  • 页面里存的共享数据（例如报名记录）和版本分开保存，恢复旧版本不会丢数据。

07分享

只有作者可以修改分享设置。在查看页点「分享」，选择谁能看到：

范围谁能看到说明
私有只有你单独授权也不生效
指定的人你单独授权的人每个人按角色获得权限
整个 workspaceworkspace 全部成员默认。成员可以查看、评论、读写页面里的共享数据
任何拿到链接的人不需要登录访客只读，不能评论；成员照常评论

单独授权

输入对方的邮箱，选择角色。对方需要先登录过一次，才能被添加。

角色可以做什么
可查看打开页面，使用页面（包括读写共享数据）
可评论以上全部，再加评论
可编辑以上全部，再加发布新版本、恢复旧版本

公开链接

  • 过期时间：7 天、30 天或永不过期。过期后访客打不开，成员不受影响。
  • 访问密码：可选。访客先输入密码才能打开；同一个访客每分钟最多试 10 次。改密码后，之前输入过的人需要重新输入。
  • 允许匿名访客写入共享数据：默认关闭。适合对外的报名表、问卷。
  • workspace 管理员可以在「Workspace 设置」里关闭公开链接；关闭后，现有的公开链接立即失效。

08连接你的 agent

只需要做一次。打开右上角头像菜单里的「Agent 接入」：

  1. 新建 token：起个名字（例如「Claude Code · 工作机」），选有效期（30 天、90 天、1 年或永不过期）。token 只显示这一次，马上复制。
  2. 连接 MCP server：页面上有 Claude Code、Codex、Cursor、Gemini CLI 四种配置，选你用的那个，复制后把 oa_pat_… 换成刚才的 token。例如 Claude Code：
claude mcp add --transport http open-artifact http://localhost:8788/mcp \
  --header "Authorization: Bearer oa_pat_…"
  1. 不支持 MCP 的 agent：复制「指南包」（AGENTS.md 片段、Claude Skill 或 Cursor rules），它告诉 agent 怎么用 HTTP API 发布。
  • agent 用你的身份工作，权限和你在这个 workspace 里一样，只在创建 token 的 workspace 里有效。
  • token 丢了或不用了，在同一页点「撤销」，立即失效。

09和 agent 协作

连接好以后，直接用自然语言告诉 agent 要做什么，例如：

把这份设计文档整理成网页，发布到 Open Artifact。 去看看「Q4 迁移看板」上给 agent 的评论，改好后重新发布并回复。 把「报名表」改成只让设计组的人看到。

完整的协作流程：

agent 能用的工具

工具作用
publish发布新的 artifact，返回链接
update基于读到的版本发布新版本；中间有人发布过时，拿到最新内容合并后再发
read读取页面文件和当前版本
list列出你能看到的 artifact
list_comments读取评论，默认只取未解决的「给 agent」评论
reply_comment回复评论，并标记为已解决
get_guide读取完整的页面规范

agent 不会自己盯着评论。同事留了「给 agent」的评论后，需要你让 agent 去处理。

10页面里的共享数据

这一节给写页面的 agent 和开发者看。页面可以通过平台注入的 window.openArtifact 保存团队共享的数据，例如报名、投票、待办：

const signups = window.openArtifact.db.collection('signups')
await signups.put('lin', { session: '周三上午' })  // 按 id 新建或替换
await signups.add({ session: '周四下午' })         // 自动生成 id
const records = await signups.list()               // [{ id, data, createdBy, updatedBy, ... }]
await signups.delete('lin')
const viewer = await window.openArtifact.viewer()  // { userId, name }；匿名访客为 null
  • 每条记录自动记下谁创建、谁最后修改。查看页的「数据」标签可以看到所有记录。
  • 集合名和 id 只能用字母、数字、-、_，最多 64 个字符；每条记录最多 64 KB。
  • 发布的页面：每个版本最多 500 个文件，单个文件最多 10 MB，一次发布最多 25 MB。
  • 页面在沙箱里运行，localStorage 和 cookie 都用不了，需要保存的东西都放共享数据里。
  • 共享数据只有在 Open Artifact 的查看页里打开时才能用，「新标签页打开」时不可用。

11设置

  • 个人资料：修改显示名称。没设置时显示邮箱 @ 前面的部分。
  • Agent 接入：token、MCP 配置、指南包（见 连接你的 agent）。
  • 成员：查看 workspace 里的所有人和管理员。
  • Workspace 设置：管理员可以开关公开链接。

12常见问题

收不到登录邮件

先看垃圾邮件，再点「再发一次」。链接 5 分钟内有效。本地试用时链接在终端里，不会真的发邮件。

提示「只有这些邮箱域名可以注册」

你的邮箱域名不在允许列表里。请管理员在部署配置 ALLOWED_EMAIL_DOMAINS 里加上你的域名。

看不到同事说的某个 artifact

它可能是私有的，或者只授权给了指定的人。请作者在「分享」里把你加进去，或者改成整个 workspace 可见。

agent 说发布时遇到了冲突

说明它读取之后，有人发布了新版本。agent 会拿到最新内容，把自己的修改合并进去再发布，不需要你处理。只有你明确要求时，它才会直接覆盖。

新标签页打开的页面提示「链接已过期或无效」

单独打开的地址 6 小时内有效。回到 Open Artifact 重新打开这个 artifact 即可。

首页缩略图是空白的

缩略图就是页面本身的缩小预览。页面需要登录后的数据才能显示内容时，预览里不会有这些数据；点开卡片就能看到完整页面。

token 不小心泄露了

在「Agent 接入」里撤销它，立即失效，再新建一个。
