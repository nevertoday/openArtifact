USER MANUAL

Open Artifact 使用手册

让任何 AI agent 把文档、报告、看板发布成网页，整个团队打开就能看、能评论、能用；再让 agent 按评论去改。

01Open Artifact 是什么

你平时让 Claude Code、Codex、Cursor 这类 agent 写设计文档、分析报告或数据看板。Open Artifact 把这些结果发布成一个个网页，叫作 artifact。同事不需要任何 AI 账号，用团队账号登录就能打开。

1

agent 发布

你对 agent 说“发布到 Open Artifact”，它把页面发上来并给你一个链接。

2

团队查看和评论

同事打开链接，在旁边写评论；需要 agent 改的，勾选「给 agent」。

3

agent 修改

你让 agent 处理评论，它改完发布新版本，再回复评论并标记已解决。

页面上的日期都写成 2026-10-20。「3 分钟前」「昨天」这类相对时间，鼠标停在上面会显示完整时间。

02登录

  1. 打开 Open Artifact 的地址，输入邮箱，点「发送验证码」。
  2. 邮件标题里就是 6 位验证码。把它填进登录页，填满 6 位自动登录。验证码 10 分钟内有效，只能用一次。
  3. 没收到邮件，等 60 秒后点「再发一次」。按钮上会倒数剩下的秒数。新验证码发出后，旧的就不能用了。
  4. 验证码输错 3 次后作废，点「再发一次」拿新的。填错了邮箱，点「换个邮箱」。
  • 能注册的邮箱由部署决定：任何邮箱、指定的邮箱域名，或者只有第一个人；被邀请的人总能注册。其他邮箱会在输入框下面看到「这个邮箱还不能注册。请让管理员邀请你。」
  • 每个人第一次登录就有自己的个人工作区，名字是「你的名字的工作区」，你是它的管理员（见 工作区）。
  • 邀请：管理员在「成员」里用邮箱邀请，或者生成一个邀请链接。收到邀请的人登录后，除了自己的个人工作区，还会加入邀请的工作区，并直接进入它；不受邮箱域名限制。邮件邀请 7 天后失效，邀请链接可以选 7 天、30 天或永不过期。
  • 如果团队配置了公司 SSO、GitHub 或 Google，登录页会多出对应的按钮。
  • 从别人发来的链接被带到登录页时，登录页写着「登录后会打开你刚才的页面。」

本地试用时没有邮件服务，验证码打印在运行 pnpm dev 的终端里，搜索 [mail]。

03工作区

artifact 都放在工作区里。一个工作区可以只有你一个人，也可以有很多人；一个人可以同时在好几个工作区。工作区的成员默认能看到里面的 artifact，你的 agent 发布到创建 token 的那个工作区。

  • 个人工作区：第一次登录时自动建好，你是管理员。可以改名，也可以邀请别人进来一起用；不能离开，也不能删除。
  • 切换：点首页左上角的工作区名字，打开工作区菜单。当前的工作区前面有勾，个人工作区标着「个人」。点另一个就切换过去，下次打开还停在这里。
  • 新建：在工作区菜单里点「新建工作区」，只要填一个名称（最多 40 个字）。建好后你是管理员，页面直接打开它的「成员」，可以马上邀请同事。
  • 邀请：管理员在「设置 › 成员」里用邮箱邀请，或者生成邀请链接。邀请链接可以选 7 天、30 天或永不过期；永不过期的链接适合贴在团队群或入职文档里，随时可以撤销。
  • 离开：在「设置 › 工作区设置」最下面点「离开」。离开后你立即看不到这里的 artifact，你在这里的 token 也失效；你发布的 artifact 留在工作区里。之后任何人邀请你，你都能回来。最后一位管理员不能离开，要先把别人设为管理员，或者删除工作区。
  • 删除：管理员在同一个位置点「删除工作区」。所有成员立即失去访问，其中的 artifact、公开链接和 token 都停止工作；agent 用这个工作区的 token 时会收到「工作区已删除」。30 天内，管理员可以在工作区菜单的「最近删除」里恢复，一切照旧；30 天后连同 artifact 和文件彻底删除。
  • 被移除：管理员把你移出一个工作区后，你登录还是进自己的个人工作区；只有管理员用邮件重新邀请你，才能回到那个工作区。
  • 用量上限：每个工作区最多 1,000 个 artifact、1 GB 文件和共享数据，每个版本的文件都算在内；「设置 › 工作区设置」的「用量」显示用了多少。删除的 artifact 立即不占数量，但它的文件和数据要到 30 天后彻底删除时才释放空间；想马上腾出空间，在首页「最近删除」里点「永久删除」。另外，每个人 24 小时内最多发布 300 次（新 artifact 和新版本都算，网页和所有 token 合计），除个人工作区外最多创建 10 个工作区（删除的工作区在彻底删除前仍然算）。到了上限，这次操作不会保存，agent 会收到原因。

04首页

首页列出你能看到的 artifact，最近更新的在前面。每张卡片上有：

  • 页面的实时缩略预览（最前面的 12 张卡片）。
  • 标题，以及谁用什么发布的，例如「devin 用 Claude Code 发布」「devin 在网页上发布」。
  • 版本号和更新时间。
  • 可见范围，例如「工作区内可见」。公开链接还会写有没有密码、哪天过期，例如「公开链接 · 有密码 · 2026-12-06 过期」。
  • N 条未解决评论：这个 artifact 上还有没解决的评论。

左侧筛选

分组选项列出什么
筛选全部你能看到的全部 artifact
我发布的你发布的，和你的 agent 代你发布的
分享给我的作者把你加进分享名单的 artifact，来自任何工作区
最近删除删除后 30 天内可以恢复的 artifact（见 删除和恢复）
待处理等我处理有评论在等你回复
等我的 agent 处理你的 artifact 上有给 agent 的评论还没解决
来源每个 agent 一项，网页发布的叫「网页」这个来源发布的 artifact

每一项后面的数字是 artifact 的个数。列表标题跟着筛选变，下面一行写这个列表装的是什么，再下面是个数。

搜索

顶部搜索框写着「搜索标题、作者或 agent」。边打字边筛选，按回车也可以。搜索只在选中的筛选和来源里进行，结果行写成「搜索「季度」· 2 个」。

列表为空时

空列表会说明原因。例如搜索没有结果时写「没有找到「xyz」」，下面有「清除搜索」，只清掉搜索，保留筛选；「分享给我的」为空时写「还没有人把 artifact 分享给你」。

其他

  • 还没设名字的人，首页顶部会看到「设置你的名字」，点「去设置」到个人资料里填写（见 设置）。
  • 左上角是工作区菜单，用来切换和新建工作区（见 工作区）。
  • 「分享给我的」跟着人走：别人单独分享给你的 artifact，不论在哪个工作区都列在这里，来自其他工作区的卡片上标着那个工作区的名字。其他筛选只看当前工作区。
  • 工作区里还没有 artifact 时，管理员会在空列表下看到「连接 agent」和「邀请成员」。

05查看 artifact

点开一张卡片进入查看页：左边是页面本身，右边是「评论」「版本」「数据」三个标签。顶部写着作者、发布来源和更新时间，旁边是可见范围。

  • 页面在沙箱里运行，和 Open Artifact 不在同一个网站。页面里的代码拿不到你的登录信息，所以 agent 写的任何页面都可以放心打开。
  • 「在新标签页打开」用整个标签页显示页面。左上角「返回查看页」回到评论和版本。
  • 作者能看到「分享」按钮，用来改谁能看到（见 分享）。
  • 右上角的「⋯」菜单里有「重命名」（能编辑的人）和「删除」或「下架」（见 删除和恢复）。

没有权限时

  • 同一个工作区的成员打开一个没分享给自己的 artifact，会看到「你没有这个 artifact 的访问权限」和作者的名字。点「请作者分享给你」，作者会在通知里和邮件里收到你的请求。
  • 工作区以外的人打开，只会看到「找不到这个 artifact」。

06评论和「给 agent」

能评论的人在右侧「评论」标签底部写评论。

  • 在页面上标注位置：写评论前点「在页面上标注位置」，再点页面上要说的地方。页面上会出现带编号的标记，评论旁边显示同样的编号；点页面上的标记，右边会跳到对应的评论。已解决的评论不再显示标记。
  • 勾选「给 agent」：这条评论是给 agent 的修改意见。agent 读取评论时只会拿到这类未解决的评论，不会被普通讨论干扰。这类评论用黄色标出。
  • 回复：每条评论下面可以回复。agent 的回复会标出是哪个 agent，例如「Claude Code（代 林舟）」。
  • 标记已解决 / 重新打开：处理完的评论标记为已解决，需要时可以重新打开。
  • 上方的筛选：未解决、给 agent、全部。
  • 别人刚写的评论会出现「有 N 条新评论」，点它显示。

07通知

右上角的铃铛列出和你有关的事，点一条打开对应的 artifact 或评论。「全部标为已读」清掉未读数。自己做的事不会通知自己。

什么时候谁收到邮件
有人评论你的 artifact作者有
有人回复你参与的评论参与这条评论的人有
有人解决了你的评论写这条评论的人有
发布了新版本还有未解决评论的参与者没有
有人把 artifact 分享给你被添加的人有
你的 agent 把 artifact 设为公开链接作者有
有人请你分享作者有

08版本

  • agent 每次修改都会发布一个新版本，旧版本全部保留。「版本」标签列出每个版本的发布人、发布来源、时间和一句改动说明，最新版本标着「最新」。
  • 点「查看」打开旧版本。页面顶部写明你在看哪个版本、谁在什么时候发布的，以及最新版本是第几版。点「看最新版本」回到最新版本。
  • 能编辑的人可以点「用 vN 覆盖最新版本」：确认后，vN 的内容作为一个新版本发布，列表里标着「恢复自 vN」，历史不会被改写。新版本的发布来源沿用 vN 的来源。发布后提示里有「撤销」，点它会再发布一个版本，换回覆盖前的内容。
  • 页面里存的共享数据（例如报名记录）和版本分开保存，覆盖版本不会丢数据。

09分享

只有作者可以修改分享设置。在查看页点「分享」，改完点「保存」才生效；没保存就关掉，对话框会先问你要不要放弃修改。

可见范围谁能看到说明
私有只有你自己添加的人也看不到
指定的人只有你添加的人每个人按权限使用
工作区内可见工作区全部成员默认。成员可以查看、评论，也能读写页面里的共享数据
公开链接任何拿到链接的人，不用登录访客只看到最新版本的页面，看不到版本记录和数据；成员照常评论

添加的人

输入对方的邮箱，选择权限。对方需要先登录过一次，才能被添加。保存后，新添加的人会收到通知和邮件。除了「私有」，其他可见范围下也可以添加人，给某个人比其他人更多的权限，比如可编辑。

权限可以做什么
可查看打开页面，使用页面（包括读写共享数据）
可评论以上全部，再加评论
可编辑以上全部，再加发布新版本、用旧版本覆盖最新版本、重命名

公开链接

  • 有效期：永不过期、7 天后或 30 天后过期。过期后访客打不开，成员不受影响。agent 设公开链接时没说多久，链接 7 天后过期，作者会收到通知。
  • 访问密码：可选。访客先输入密码才能打开。密码输错会看到「密码不对，再试一次。」；同一个访客一分钟里试错太多次，会看到「1 分钟后可以再试」。改密码后，之前输入过的人需要重新输入。
  • 允许匿名访客写入共享数据：默认关闭。适合对外的报名表。
  • 对外显示评论：访客可以看到评论和评论人的名字，但不能发表评论。
  • 工作区管理员可以在「工作区设置」里关闭公开链接；关闭后，现有的公开链接立即失效。
  • 举报：通过公开链接打开页面的人，不论是否登录，都能点顶栏的「举报」，选原因、补充说明，交给这个 Open Artifact 的运营方。运营方下架的页面，作者和工作区管理员都不能恢复，30 天后彻底删除。

10删除和恢复

  • 作者在查看页的「⋯」菜单里点「删除」。管理员处理别人的 artifact 时，这一项叫「下架」。
  • 删除或下架后，所有人都看不到这个 artifact。首页会出现提示，里面有「撤销」。
  • 它在「最近删除」里留 30 天，点「恢复」就回来了；30 天后彻底删除。
  • 作者可以恢复自己删除的 artifact。被管理员下架的，作者不能自己恢复，只有管理员可以。

11连接你的 agent

只需要做一次。打开右上角头像菜单里的「Agent 接入」，按三步走：

  1. 给这个 agent 起个名字：例如「Claude Code · 工作机」。选有效期（90 天、30 天、1 年或永不过期）和权限，点「新建 token」。
    • 仅发布：发布、更新和读取 artifact，处理评论和共享数据；不能修改谁能看到它。
    • 完全权限：和你在网页上能做的一样，也能修改分享设置，比如设为公开链接。
  2. 把配置填进 agent：token 只显示这一次。选你用的 agent（Claude Code、Codex、Cursor、Gemini CLI 或其他（HTTP）），复制配置，token 已经填好了。改完配置后重启 agent。例如 Claude Code：
claude mcp add --transport http open-artifact http://localhost:8788/mcp \
  --header "Authorization: Bearer oa_pat_…"
  1. 让 agent 发布一个测试页：把页面上的那句话发给 agent。页面发布后，这里会显示「连上了」。
  • 不支持 MCP 的 agent 选「其他（HTTP）」，先让它读 llms.txt，里面写了全部接口。
  • 「指南包」（AGENTS.md 片段、Claude Skill、Cursor rules、llms.txt）告诉 agent 什么时候发布、页面要遵守什么约定、该更新而不是新建。
  • agent 用你的身份工作，只在创建 token 的工作区里有效。

已有的 token

  • 列表写着每个 token 的名字、权限、最近使用、到期（例如 2027-02-04 或「永不过期」）和状态。
  • token 丢了或不用了，点「撤销」，立即失效。撤销后不能恢复，只能新建一个。
  • 已撤销和已过期的 token 收在「显示已失效的 token（N）」里，每个都可以「删除」。
  • agent 用了不能用的 token，会分别收到「已撤销」「已过期」「无效」三种错误，知道该请你新建一个。

12和 agent 协作

连接好以后，直接用自然语言告诉 agent 要做什么，例如：

把这份设计文档整理成网页，发布到 Open Artifact。 去看看「Q4 迁移看板」上给 agent 的评论，改好后重新发布并回复。 把「报名表」改成只让设计组的人看到。（需要完全权限的 token）

完整的协作流程：

agent 能用的工具

工具作用
publish发布新的 artifact，返回链接
update基于读到的版本发布新版本；中间有人发布过时，拿到最新内容合并后再发
read读取页面文件和最新版本
list列出你能看到的 artifact
list_my_comments列出你能编辑的所有 artifact 上未解决的「给 agent」评论
list_comments读取一个 artifact 的评论，默认只取未解决的「给 agent」评论
reply_comment回复评论，并标记为已解决
get_guide读取完整的页面规范

agent 不会自己盯着评论。同事留了「给 agent」的评论后，需要你让 agent 去处理。首页的「等我的 agent 处理」列出这些 artifact。

13页面里的共享数据

这一节给写页面的 agent 和开发者看。页面可以通过平台注入的 window.openArtifact 保存共享数据，例如报名、投票、待办：

const signups = window.openArtifact.db.collection('signups')
await signups.put('lin', { session: '周三上午' })  // 按 id 新建或替换
await signups.add({ session: '周四下午' })         // 自动生成 id
const records = await signups.list()               // [{ id, data, createdBy, updatedBy, ... }]
await signups.delete('lin')
const viewer = await window.openArtifact.viewer()  // { userId, name }；匿名访客为 null
  • 每条记录自动记下谁创建、谁最后修改。查看页的「数据」标签可以看到所有记录。
  • 集合名和 id 只能用字母、数字、-、_，最多 64 个字符；每条记录最多 64 KB，每个页面最多 2,000 条、共 5 MB，算在工作区的存储空间里。没有登录的访客，同一个网络每分钟最多改 60 次。
  • 发布的页面：每个版本最多 500 个文件，单个文件最多 10 MB，一次发布最多 25 MB。
  • 页面在沙箱里运行，localStorage 和 cookie 都用不了，需要保存的东西都放共享数据里。
  • 共享数据在查看页和「在新标签页打开」的页面里都能用。

14设置

  • 个人资料：修改名字，最多 60 个字。团队成员在评论、通知和成员列表里看到它。没设名字时，别人看到的是你邮箱 @ 前面的部分。邮箱用来登录，不能修改。
  • Agent 接入：token、agent 配置、指南包（见 连接你的 agent）。
  • 成员：工作区里的所有人，管理员排在前面，你自己的名字后面写着「（你）」。角色是「管理员」或「成员」。管理员可以邀请同事、改角色、移除成员；工作区至少要有一位管理员，管理员也不能移除自己。被移除的人发布的 artifact 会留在工作区里。
  • 工作区设置：
    • 管理员可以改工作区的名称，最多 40 个字。
    • 「允许成员把 artifact 分享为公开链接」开关。管理员关闭时，确认框会写明「关闭后，N 个公开链接立即失效。」成员只能看到「已允许」或「已关闭」，旁边写着「只有管理员可以修改」。
    • 管理员还能看到「内容管理」（工作区里的全部 artifact，可以下架和恢复）和「管理记录」（删除、下架、恢复、重命名、邀请、成员变动，以及工作区的删除和恢复）。
    • 最下面是「离开或删除」：所有人都能离开，管理员还能删除工作区（见 工作区）。个人工作区这里只有一句说明。

15常见问题

收不到登录邮件

先看垃圾邮件，60 秒后再点「再发一次」。链接 5 分钟内有效。本地试用时链接在终端里，不会真的发邮件。

提示「这个邮箱还不能注册」

这个部署只允许部分邮箱注册，你的邮箱不在其中，也没有收到邀请。请管理员在「成员」里邀请你，或者把邀请链接发给你。

不小心删除了工作区

30 天内，管理员在首页左上角的工作区菜单里点「最近删除」，再点「恢复」。成员、artifact、公开链接和 token 都会回来。

打开同事说的 artifact，提示没有访问权限

它是私有的，或者只分享给了指定的人。点「请作者分享给你」，作者会收到通知和邮件。

agent 说发布时遇到了冲突

说明它读取之后，有人发布了新版本。agent 会拿到最新内容，把自己的修改合并进去再发布，不需要你处理。只有你明确要求时，它才会直接覆盖。

页面里提示 “This link has expired or is not valid”

页面文件的地址 6 小时内有效。刷新 Open Artifact 的页面，或者回到首页重新打开这个 artifact。

首页缩略图是空白的

缩略图就是页面本身的缩小预览。页面需要登录后的数据才能显示内容时，预览里不会有这些数据；点开卡片就能看到完整页面。

token 不小心泄露了

在「Agent 接入」里撤销它，立即失效，再新建一个。

不小心删除了 artifact

首页提示里点「撤销」；提示消失了，就到「最近删除」里点「恢复」。30 天内都可以恢复。
