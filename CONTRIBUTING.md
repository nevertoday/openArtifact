# Contributing / 参与

Thank you for your interest in Open Artifact.

- **Issues are welcome**: bugs, ideas and questions. For a bug, say what you did, what you expected and what happened, and which browser or agent you used.
- **Code contributions are not accepted yet.** Open Artifact is under the PolyForm Noncommercial License and is also licensed commercially; taking outside code would need a contributor license agreement, which is not in place. Pull requests will be closed with thanks. If a fix matters to you, describe it in an issue and it may be built.
- **Security problems** go through [SECURITY.md](SECURITY.md), not an issue.

感谢你关注 Open Artifact。

- **欢迎提 issue**：bug、想法和问题都可以。报告 bug 时请写清楚你做了什么、预期是什么、实际发生了什么，以及用的浏览器或 agent。
- **目前不接受代码贡献。** Open Artifact 以 PolyForm Noncommercial 许可证公开，同时提供商业授权；接受外部代码需要贡献者授权协议（CLA），目前还没有。Pull request 会被感谢后关闭。如果某个修复对你很重要，请在 issue 里描述，我们可能会实现它。
- **安全问题**请按 [SECURITY.md](SECURITY.md) 报告，不要开 issue。
